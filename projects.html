Project: 3D Printing & Design

Bambu Lab H2D Printer Setup & Calibration

Comprehensive exploration of professional 3D printing technology, focusing on FDM mechanics, print quality optimization, and advanced slicing techniques.

Project Highlights

  • Hardware: Bambu Lab H2D CoreXY printer with 256x256x256mm build volume
  • Materials: PLA, PETG, TPU, and engineering-grade thermoplastics
  • Key Skills: Printer calibration, layer optimization, support generation, design-to-print workflow
  • Applications: Rapid prototyping, functional parts, aesthetic models

Slicing & Print Optimization

Mastered advanced slicing techniques using Bambu Studio to achieve optimal print quality, speed, and material efficiency.

Technical Achievements

  • Configured layer heights from 0.08mm to 0.20mm for quality-to-speed balance
  • Implemented tree supports to minimize material waste and post-processing time
  • Optimized cooling profiles for different material types
  • Achieved dimensional accuracy within ±0.5mm tolerance

Project: Laser Cutting & Design

CO2 Laser Cutter Operation & Design

Hands-on experience with CO2 laser cutting technology for precision cutting, engraving, and fabrication of various materials.

Project Scope

  • Equipment: 40W CO2 laser cutter with 600x400mm cutting area
  • Materials: Wood, acrylic, cardboard, leather, and fabric
  • Techniques: Vector cutting, raster engraving, 3D engraving
  • Software: CorelDRAW and LightBurn for design and control

Design to Fabrication Workflow

Complete understanding of converting digital designs into physical laser-cut and engraved products.

Workflow Steps

  • Vector design preparation and optimization
  • Material selection and thickness calibration
  • Laser power and speed optimization for different materials
  • Quality control and finishing techniques

Project: Arduino IoT & Firebase Integration

IoT Data Collection & Cloud Storage

Development of IoT systems that collect real-time sensor data and store it in Firebase for remote monitoring and analysis.

Project Components

  • Microcontrollers: Arduino Uno, Nano, Mega, and ESP32
  • Sensors: Temperature, humidity, motion, light, and pressure sensors
  • Connectivity: Wi-Fi module (ESP32) for internet connectivity
  • Backend: Firebase Realtime Database for cloud storage
  • Frontend: Web dashboard for real-time data visualization

Remote Monitoring & Control

Implemented two-way communication for real-time monitoring and remote device control through Firebase.

Key Features

  • Real-time sensor data upload to Firebase
  • Mobile/web dashboard for remote monitoring
  • Remote control of connected devices
  • Data logging and historical analysis
  • Automated alerts and notifications

Project: Embedded Systems & Microcontrollers

Microcontroller Programming & Hardware Integration

Deep dive into embedded systems programming with multiple Arduino platforms, sensor interfacing, and real-world applications.

Platforms & Skills

  • Arduino Uno: Basic microcontroller with 14 digital and 6 analog pins
  • Arduino Mega: Advanced platform with 54 digital and 16 analog pins
  • Arduino Nano: Compact form factor for space-constrained applications
  • ESP32: Powerful Wi-Fi enabled microcontroller with dual-core processor
  • Programming Language: C++ Arduino IDE

Sensor Integration & Data Processing

Integration of various sensors and actuators for real-world embedded system applications.

Hardware Integration

  • Analog sensor reading and calibration
  • Digital communication protocols (I2C, SPI, UART)
  • Motor control and PWM signals
  • LED and display interfacing
  • Power management and battery optimization
