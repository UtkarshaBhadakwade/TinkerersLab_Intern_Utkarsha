VisionAI: AI-Based Eye Disease Detection

Using Deep Learning on Fundus Images

BTech Project | CSE | Sanjivani College of Engineering

Introduction Slide 2
  • Eye diseases are a leading cause of blindness worldwide
  • Early detection is critical but requires specialist expertise
  • Manual diagnosis is time-consuming and error-prone
  • AI-based automation offers fast, accurate screening
Problem Statement Slide 3
  • Limited availability of ophthalmologists in rural areas
  • Delayed diagnosis leads to irreversible vision loss
  • Existing systems classify fewer disease categories
  • Need for a multi-disease, accurate, and deployable solution
Objectives Slide 4
  • Classify fundus images into 6 disease classes
  • Train and compare 5 deep learning architectures
  • Build a desktop application (VisionAI) for real-time detection
  • Identify best model for edge deployment (Raspberry Pi)

Key Observation Slide 10
  • Diabetes and Normal classes were hardest to classify across all models
  • EfficientNetV2-S gave best accuracy with stable training
  • CNN models converged faster than Transformers
  • FNet was fastest to train but least accurate
VisionAI Application Slide 11
  • Built using PyQt5
  • Supports image upload, webcam, and video input
  • Real-time inference using trained models
  • Multi-threaded for smooth UI experience
Design Slide 12
  • 3D model of optical lens designed in Fusion 360
  • Represents hardware component for fundus capture
  • App interface supports all 5 models
Conclusion Slide 13
  • Successfully trained 5 models on 6-class fundus dataset
  • EfficientNetV2-S identified as best performing model
  • VisionAI app built for real-time disease detection
  • System ready for future edge deployment
Future Scope Slide 14
  • Deploy on Raspberry Pi 5
  • Add more disease classes
  • Integrate with hospital systems
  • Improve Diabetes class accuracy with targeted augmentation
